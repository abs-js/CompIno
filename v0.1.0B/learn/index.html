Learn CompIno

Version 0.1.0-beta.0. CompIno writes Arduino sketches so the board program can stay short.

1. Run it

npx compino@beta blink.cno

That writes blink.ino. Open the .ino file in the Arduino IDE and upload it.

2. A whole sketch

Lines before &{ } run once. Lines inside run forever.

writable(@7)
&{
  @7 = true
  sleep(500)
  @7 = false
  sleep(500)
}

3. Names and pins

  • $name is a variable.
  • @7 is digital pin 7. writable(@7) makes it an output.
  • ~5 is analog pin 5. A read is 0 to 1023.
  • serial("hello") prints a line.

4. Choices and loops

if (~5 > 500) {
  @7 = true
} else {
  @7 = false
}

Use and, or, xor, and !. while (condition) { } repeats a block.

5. Functions and classes

func somar ($a, $b) {
  return $a + $b
}

class Algo {
  _texto = "hello"
  func _main ($coisa) {
    _algo = $coisa
  }
  Main _main
}

Outside the class, _texto is used as .texto.

6. Flags

  • -h help
  • -v version
  • -d detailed transpile log
  • -l open this page

Full reference: docs/LANGUAGE.md in the package.
