# CompIno

CompIno is a simple language for Arduino boards. A `.cno` file is transpiled into a `.ino` sketch.

Versions are stored in folders so each release stays readable:

- `v0.1.0B/` — first beta (`0.1.0-beta.0`)
- `v0.1.1B/` — slim sketches, English examples, stricter errors (`0.1.1-beta.0`)

Stable cuts use `v0.1.0/`. Beta cuts use a `B` suffix, such as `v0.1.0B/`.

Repository: https://github.com/abs-js/CompIno
