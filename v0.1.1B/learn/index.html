Learn CompIno

Version 0.1.1-beta.0. The generated sketch keeps only what the program uses.

Run

npx compino@beta blink.cno

Open the written .ino in the Arduino IDE and upload it.

Blink

writable(@7)
&{
  @7 = true
}

That becomes pinMode(7, OUTPUT) and digitalWrite(7, HIGH).

Names

  • $text = "hello" is a variable.
  • @7 is a digital pin. ~5 is an analog pin.
  • serial("hello") prints a line. sleep(500) waits.

A library

import Switch from "lib.cnl"
$led = new Switch(@8)
&{
  $led.turnOn()
  sleep(500)
  $led.turnOff()
  sleep(500)
}

Errors are numbered E001–E015. CompIno prints all of them and skips the .ino until they are fixed.
